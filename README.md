# 삼성생명 설계매니저 AI 실전 워크북

설계매니저(CM·GM)를 위한 90분 모바일 중심 AI 실습 워크북입니다.
내 휴대폰으로 **안내 카드 · 상품 설명 슬라이드 · 약관 Q&A 챗봇** 3가지를 직접 만듭니다.

## 페이지

- **`index.html`** — 모바일 웹 버전 (수강생이 폰에서 QR·URL로 열어 따라오는 용도)
- **`print.html`** — A4 인쇄용 워크북 (PDF 저장·출력용, 14페이지)

GitHub Pages 배포 시 기본 주소(`index.html`)가 모바일 버전입니다.

## 구성 모듈

| 모듈 | 도구 | 결과물 |
|---|---|---|
| ① | ChatGPT (앱) | 카톡용 안내 카드 이미지 |
| ② | NotebookLM (앱) | 상품 설명 슬라이드(영상 개요) |
| ③ | Gemini (크롬 웹) | 약관 Q&A 챗봇(Gem) |

## 특징

- 프롬프트 **복사 버튼** — 폰에서 타이핑 없이 붙여넣기
- 버튼 위치까지 적힌 단계별 안내 — 수업에서 못 끝내도 혼자 완성 가능
- 체크리스트 진행 상황 자동 저장(localStorage)
- 고객 정보·계약 정보 입력 금지 안내 반복
