도구 3개 지도4/14
Module 1 · ChatGPT

이미지 만들기 버튼 찾기

첫 결과물은 카톡으로 보낼 안내 카드입니다.
먼저 ChatGPT에서 이미지 만들기 버튼을 찾습니다.

휴대폰에서 누를 것
  1. ChatGPT 앱을 엽니다.
  2. 새 대화를 엽니다.
  3. 입력창 옆의 +를 누릅니다.
  4. 도구, More, Images 중 비슷한 이름을 찾습니다.
  5. 이미지 만들기 또는 Images를 누릅니다.

잘 되었는지 확인

입력창에 이미지 관련 표시가 생기거나,
ChatGPT가 이미지를 만들 준비가 되었다고 안내하면 성공입니다.

막히면 이렇게

메뉴가 안 보이면 그냥 입력창에 "이미지를 만들어줘"라고 입력합니다.
그래도 안 되면 앱스토어에서 ChatGPT 앱을 업데이트합니다.

안내 카드 만들기

카드에 들어갈 글자를 내가 정해서 알려주는 것이
오탈자 없는 카드를 만드는 핵심입니다.

짧은 버전 
설계사분들께 카카오톡으로 보낼
세로형 안내 카드 이미지를 만들어주세요.

카드에 넣을 글자는 아래만 사용하세요.
제목: 7월 신상품 설명회
일시: 7월 24일(금) 오전 10시
대상: 우리 지점 설계사님
한 줄 안내: 신상품 핵심을 30분에 정리해드립니다.

글자는 위 문구를 그대로, 오타 없이 넣어주세요.
상세 버전 
위 내용으로 다시 만들어주세요.
깔끔한 금융 스타일, 신뢰감 있는 파란색 계열,
배경은 단순하게, 제목이 가장 크게 보이게 해주세요.
장식용 글자는 넣지 마세요.

잘 되었는지 확인

카드 속 글자를 한 글자씩 확인합니다.
한글이 틀렸으면 "글자만 정확히 고쳐주세요"라고 다시 요청합니다.

막히면 이렇게

제목 · 일시 · 대상은 2쪽에 적은 내 주제로 바꿔도 됩니다.
단, 문구는 짧을수록 오타가 적습니다.

모듈 ① 안내 카드 만들기6/14
Module 1 · ChatGPT

카드 수정하고 카톡으로 보내기

첫 결과는 초안입니다.
한 번에 한 가지만 고치고, 저장해서 보냅니다.

휴대폰에서 누를 것
  1. 생성된 이미지를 누릅니다.
  2. 아래 수정 문장을 입력합니다. (수정이 필요할 때만)
  3. 결과가 마음에 들면 이미지를 다시 누릅니다.
  4. 저장 · Save · 다운로드 중 비슷한 버튼을 누릅니다.
  5. 카카오톡을 열어 사진으로 첨부해 보냅니다.
전체 분위기는 좋습니다.
제목 글자를 더 크게,
배경은 더 단순하게 바꿔주세요.
글자 내용은 바꾸지 마세요.

막히면 이렇게

무료 계정은 이미지 횟수가 하루 2~3장 수준입니다.
수정 요청은 1번만 하고, 옆자리와 결과를 비교해봅니다.

Module 2 · NotebookLM

NotebookLM 열고 자료 넣기

NotebookLM은 내가 올린 자료 안에서만 답하는 도구입니다.
먼저 상품 자료 PDF를 넣습니다.

휴대폰에서 누를 것
  1. 카카오톡에서 받은 상품 자료 PDF를 열고, 공유 · 저장 버튼으로 휴대폰에 저장합니다.
  2. NotebookLM 앱을 엽니다.
  3. 새로 만들기 또는 +를 누릅니다.
  4. 소스 추가 화면에서 PDF 또는 파일을 누릅니다.
  5. 방금 저장한 상품 자료 PDF를 선택합니다.

잘 되었는지 확인

소스 목록에 파일 이름이 보이고,
요약이나 질문 제안이 나타나면 성공입니다.

막히면 이렇게

파일이 안 보이면 1번(휴대폰에 저장)을 건너뛴 경우입니다.
카카오톡으로 돌아가 파일을 먼저 저장하고 다시 시도합니다.

모듈 ② 자료 넣기8/14
Module 2 · NotebookLM

상품 설명 슬라이드 만들기

GA 교육 · 브리핑에 쓸 슬라이드를
버튼 하나로 초안까지 만듭니다.

휴대폰에서 누를 것
  1. 화면 아래 또는 상단에서 스튜디오 메뉴를 찾습니다.
  2. 슬라이드 또는 영상 개요를 찾습니다.
  3. 항목 옆의 > 또는 연필 모양을 눌러 지침 입력 화면을 엽니다.
  4. 아래 지침을 붙여넣고 생성을 누릅니다.
지침 (붙여넣기) 
보험 설계사에게 이 상품을 설명하는 슬라이드를 만들어주세요.
상품의 핵심 보장 3가지를 중심으로, 쉬운 말로 정리해주세요.

디자인은 아래 스타일로 만들어주세요.
Minimalist infographic, simple flat vector art,
clean data visualization, corporate color palette,
white background, highly legible

막히면 이렇게

생성에는 몇 분이 걸립니다. 기다리지 말고 11쪽 모듈 ③을 먼저 진행합니다.
지침 입력 화면을 못 찾으면 지침 없이 그냥 생성해도 됩니다.

모듈 ② 슬라이드 만들기9/14
Module 2 · NotebookLM

슬라이드 확인하고 공유하기

AI가 만든 요약은 반드시 원자료와 대조합니다.
확인이 끝나면 링크로 공유합니다.

휴대폰에서 누를 것
  1. 완성 알림이 오면 슬라이드(영상)를 엽니다.
  2. 한 장씩 넘기며 내용을 봅니다.
  3. 상품명과 숫자를 원자료와 대조합니다.
  4. 공유 버튼을 눌러 링크 복사를 찾습니다.
  5. 복사한 링크를 나에게 카톡으로 보내봅니다.

잘 되었는지 확인

  • 슬라이드가 재생되고, 상품 핵심이 담겨 있다.
  • 보장금액 · 보험기간 같은 숫자가 원자료와 같다.
  • 링크가 카톡으로 전송된다.

막히면 이렇게

숫자가 틀렸으면 그 슬라이드는 쓰지 않습니다.
생성이 너무 오래 걸리면 오디오 개요를 먼저 만들어 들어봅니다.
슬라이드는 강의 후 완성해도 충분합니다.

이 슬라이드를 쓸 자리 (GA 교육 · 조회 · 브리핑)

모듈 ② 확인과 공유10/14
Module 3 · Gemini

크롬에서 챗봇 틀 만들기

약관 챗봇은 Gemini의 Gem 기능으로 만듭니다.
중요: Gemini 앱이 아니라 크롬 브라우저에서 만듭니다.

왜 크롬인가

Gemini 앱에는 아직 챗봇(Gem) 만들기 버튼이 없습니다.
크롬으로 gemini.google.com에 들어가면 만들 수 있습니다. (2026년 7월 기준)

휴대폰에서 누를 것
  1. 크롬 앱을 엽니다.
  2. 주소창에 gemini.google.com을 입력합니다.
  3. 구글 계정으로 로그인되어 있는지 확인합니다.
  4. 왼쪽 위 메뉴(≡)를 누릅니다.
  5. Gem, Gem 관리자, Explore Gems 중 비슷한 이름을 누릅니다.
  6. Gem 만들기 또는 + 새 Gem을 누릅니다.

막히면 이렇게

주소를 눌렀는데 Gemini 앱이 열리면,
크롬 주소창에 직접 입력해서 다시 들어갑니다.
메뉴에서 Gem이 안 보이면 화면을 아래로 내려 찾아봅니다.

모듈 ③ 챗봇 틀 만들기11/14
Module 3 · Gemini

약관을 학습시키는 지침

챗봇의 실력은 지침이 결정합니다.
약관 안에서만 답하게 만드는 것이 핵심입니다.

휴대폰에서 누를 것
  1. 이름 칸에 "상품 약관 도우미"라고 입력합니다.
  2. 지침 칸에 아래 문장을 붙여넣습니다.
  3. 지식 · 파일 추가에서 미리 받은 약관 PDF를 올립니다.
  4. 저장을 누릅니다.
지침 (붙여넣기) 
당신은 보험 상품 약관 안내 도우미입니다.

답변 규칙:
1. 업로드된 약관 문서에서만 근거를 찾아 답합니다.
2. 답변 끝에 근거가 된 조항 번호를 표시합니다.
3. 약관에서 확인되지 않는 내용은
   "약관에서 확인되지 않습니다"라고만 답합니다.
4. 어려운 용어는 쉬운 말로 풀어 설명합니다.
5. 모든 답변 마지막에 이렇게 붙입니다.
   "정확한 내용은 약관 원문과 회사 공식 안내를 확인하세요."

막히면 이렇게

파일 업로드 버튼이 안 보이면 지침만 저장하고,
대화 시작 후 클립 모양 버튼으로 약관 PDF를 첨부해도 됩니다.

모듈 ③ 지침과 약관 학습12/14
Module 3 · Gemini

현장 질문으로 테스트

챗봇은 만들고 끝이 아니라, 시험해보고 씁니다.
일부러 함정 질문도 하나 던져봅니다.

테스트 질문 1 
이 상품에서 보험금이 지급되지 않는 경우를
쉬운 말로 정리해주세요.
근거 조항도 함께 알려주세요.
테스트 질문 2 (함정) 
이 약관에 없을 것 같은 내용을 하나 물어봅니다.
예: 자동차 수리비도 보장되나요?

잘 되었는지 확인

  • 답변에 조항 번호가 붙어 나온다.
  • 약관에 없는 질문에는 "확인되지 않습니다"라고 답한다.
  • 답변 끝에 공식 안내 확인 문구가 붙는다.

막히면 이렇게

함정 질문에 그럴듯한 답을 지어내면, 지침 3번이 빠진 것입니다.
Gem 수정 화면에서 지침을 다시 확인합니다.
